# Odoo Addons

Custom Odoo modules developed by Bassel Nubiaa, based on business requirements
from Odoo implementation projects in construction, gold retail, trading and
distribution, and service operations.

## Branches

| Branch | Odoo version |
|--------|--------------|
| `17.0` | 17.0         |
| `18.0` | 18.0         |
| `19.0` | 19.0         |

## Modules

No modules are available for this version yet. See the `17.0` branch for
published modules.

## Installation

```bash
git clone -b 18.0 https://github.com/Bassel-Nubiaa/odoo-addons.git
```

Replace `18.0` with the branch corresponding to the target Odoo version. Add the
cloned directory to the `addons_path` of the Odoo instance, restart the server,
update the Apps list, and install the required modules.
