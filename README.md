## Installation

1. Clone the branch matching your Odoo version:
   ```bash
   git clone -b 17.0 https://github.com/Bassel-Nubiaa/odoo-addons.git
   ```
2. Add the cloned folder to your Odoo `addons_path`.
3. Restart Odoo, update the Apps list, and install the module.
